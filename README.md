# Zomato Data Analysis Dashboard | Power BI

## 📊 Project Overview
This project focuses on analyzing Zomato restaurant data using **Microsoft Power BI** to uncover insights into customer preferences, restaurant performance, cuisine popularity, pricing trends, and online ordering behavior. The interactive dashboard transforms raw restaurant data into meaningful visualizations that support data-driven decision-making.

## 🎯 Objectives
- Analyze the most popular cuisines and restaurant types.
- Identify areas with the highest number of restaurants.
- Understand restaurant rating patterns across different locations.
- Analyze customer preferences for online ordering and table booking.
- Explore cost distribution and average dining costs across restaurants.
- Build an interactive dashboard to visualize key business insights.

## 🗂️ Dataset
- **Total Records:** 7,105
- **Columns:** 12 initially, reduced to 11 after cleaning.
- **Key Features:** Restaurant Name, Restaurant Type, Cuisine, Rating, Cost for Two, Area, Online Order, and Table Booking.

## 🧹 Data Cleaning
- Removed unnecessary index columns.
- Handled missing values in ratings and cost using median imputation.
- Standardized Yes/No values for online ordering and table booking.
- Cleaned cuisine and area names using Trim and Clean operations.
